# 01. COMPANY OVERVIEW

## About Merantaw

Merantaw is an independent indie game and interactive studio based in Magelang, Indonesia, founded in 2024 by Farrel Apriandry.

The studio works across game development, software, web and mobile development, 3D production, UI/UX, research and development, and prototyping.

Merantaw aims to build meaningful interactive experiences while contributing to the growth of Indonesia's game development community and introducing Indonesian culture to audiences beyond Indonesia.

Merantaw currently operates as an independent studio and has not yet established a formal legal entity.
